# ROB 599: Physically-Grounded AI Agents

University of Michigan, Fall 2026.

Two things happen here. We read the [paper hub](../../paper-hub/) as a whole and say
what we make of it. And we hold debate sessions that go deep on a few papers at a time.

```
syllabus.md     what the course covers, week by week
lectures/       lecture notes, one Jupyter notebook per lecture
slides/         the decks
debates/        one file per session: the topic, the papers, the sides, what came out
recordings.md   links to the Zoom recordings
```

A folder appears when its first file does.

# Exploratory / someday (P3)

- **[P3] Course projects feed back into the list.** The project note's ambition is that
  ROB 599 students produce papers that land here. That needs a contribution path —
  probably a PR template mirroring the add-a-paper flow.
- **[P3] Coverage honesty as a first-class view.** The list currently says nothing about
  what it is missing. A view that showed which cells of the taxonomy are empty would
  make the gaps legible to a reader instead of only to the maintainer.
- **[P3] Citation edges between entries.** Which papers on the list cite which others,
  pulled from Semantic Scholar. Would turn the taxonomy into a graph and make "these
  two literatures barely cite each other" a measurement rather than a claim in a blurb.
- **[P3] Per-paper reading state.** If the list is used for a course, "assigned",
  "discussed", "student-presented" are natural columns. Only if it does not turn the
  reference into a syllabus — see `../../dev-handbook/mission.md`.
